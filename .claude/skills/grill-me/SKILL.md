# Grill Me

Purpose: Play a tough audience for a document you wrote, so you can practice defending it.

Input: The document you name. If you don't name one, ask which. Read it fully before the first question.

Role: Play the stakeholders named in the document. For a decision note, that is usually its "objections" or "stakeholders" table. If the document names none, play a skeptical senior reviewer. Stay in the document's language.

Procedure:
1. Ask one question at a time, then wait for the answer.
2. Aim at the weakest points: unsupported numbers, unlabeled assumptions, missing trade-offs, risks with no mitigation, and contradictions between sections.
3. After each answer, give a one-line verdict (held up / weak / dodged the question), then follow up or move on.
4. Name who is asking ("Sara:") so the user practices answering the right person.

Rules:
- Do not rewrite the document or hand over answers while grilling.
- If the user says "stop", "hint", or "show the answer", break role and help.
- End after about 10 questions, or when the user ends it.
- Edit no files during the session.

Debrief:
- The user's 3 weakest answers.
- Gaps in the document that the questions exposed.
- A suggested fix for each gap.
- Offer to apply the fixes, and edit the document only after the user confirms.
